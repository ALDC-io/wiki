### FU92-397 — NetSuite PO Employee Bug (New)

Juliann reported that POs created from DAX via "Sync with NetSuite" show the wrong employee name. Example: PO001188 shows Tom Hammond, but the flight was created by Michael Child and synced by Noah Elliot.

**Root cause identified:** The `employee` field on the PO is set to the project manager of the NetSuite project (job), not the person who triggered the sync. Code path: `workflows/netsuite.py` line 496 sets `"employee": {"id": project_manager_id}` where `project_manager_id` comes from the NetSuite project's `projectmanager` field. Different projects have different PMs — that's why the name varies.

**Additional findings:**
- `ALDC_NETSUITE_EMPLOYEE_ID` env var declared but never used (dead code)
- Frontend only sends `{account_id, flight_id}` — no user identity reaches the backend

**Proposed fix:** Pass the logged-in user's identity from the frontend (via `getServerSession()`), look them up in NetSuite as an employee via SuiteQL, and use their employee ID on the PO. Fallback to `ALDC_NETSUITE_EMPLOYEE_ID` if no match.

**Status:** Root cause + fix plan drafted. Email sent to Lori (EI Lead) to confirm with Juliann before implementing. Jira ticket FU92-397 created. Wiki page created.

### FU92-396 — DAX Manual Metrics Stale JWT Role Fix (Resolved)

Ken Kocna unable to enter Manual Metrics on flights in "Change Submitted" and "Approved" status. Error: "Entry unavailable due to flight status or user role."

**Root cause:** JWT callback in `authOptions.ts` cached user roles from login time and never re-fetched from CosmosDB. Ken's role was `buyer` in the database but his session still carried stale `user` role.

**Fix:** Added periodic (5-min TTL) role refresh from CosmosDB via `user/list` core API endpoint in the JWT callback. Also hardened CI/CD: pinned action SHAs, added type-check + tests to PR checks, added `/api/health` endpoint + post-deploy health check to deploy workflow.

**Validation:** Reproduced the bug in production (changed own role to `user` → saw error), changed to `buyer` without logging out, confirmed role auto-refreshed and metrics table unlocked. Verified via `/api/auth/session` endpoint and Azure log stream.

**Deployed to production** via PR #35 → merge → GitHub Actions deploy → slot swap. Jira transitioned to Ready for Customer. Email drafted for Lori.
