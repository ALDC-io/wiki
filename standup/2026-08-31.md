**Today (2026-08-31) — continuing: the GP-319 build process**

Three read-only investigation stages run in parallel, then five design stages run in sequence:

| Stage | Output |
|---|---|
| **R1** | Stakeholder + client-evidence reconstruction — what GEP actually asked for, and when |
| **R2** | Repo and wiki **diff** — what is locked, what is stale, what is missing |
| **R3** | Snowflake cartography — what marketing data exists, at what grain, with what keys |
| **D1** | Requirements synthesis, each item graded CONFIRMED / SUPPORTED / INFERRED / ASSUMPTION / UNKNOWN |
| **D2** | Analytical question catalogue — the questions the model must be able to answer |
| **D3** | Candidate dimensional designs — **grain declared before any design work** |
| **D4** | Skeptical review — actively try to falsify D3's grain and key claims |
| **D5** | Recommendation + human sign-off |

Every measure gets censused against every axis, so an inert one cannot ship looking healthy, and
`MEASURED / DERIVED / NOT-REPORTED / SENTINEL` stay distinct so an absence never renders as a zero.
