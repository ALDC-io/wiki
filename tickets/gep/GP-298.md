# GP-298 — Brinno Dashboard: refine trend-comparison columns

Lori (EI Lead) asked to change which measures show Prev %/YoY % trend-comparison
columns on the NAVIRA brand dashboards: **Sales table → Gross only** (drop Buy Box %
+ Return Rate % comparison), **Units table → Quantity only**. Confirmed **global**
across all brand dashboards (Paul + Lori, 2026-07-24). Same family of measure-presentation
refinement as GP-256 / GP-259 / GP-263.

**Status (2026-07-24):** applied to PROD + validated at the rendered layer; **in GEP QA**
(client QA pending). Not yet Done. QA resume prompt: `aldc-launchpad/boot-prompts/gp298-qa-resume.md`.

Delivered as a **data-only** edit to shared `explorer_visual` `options` in the current
eclipse-2.1 dashboards — see [[dashboard]] for the `comparison_measures` mechanism and the
three gotchas this ticket surfaced.

## Change (PROD Cosmos `aldcprodcsdb1c01`/`core`, account `da8904db`)

| Visual | id | edit | dashboards |

| Sales by SKU w/RR% | `1807e81d` | `comparison_measures=["Actual - Sales - Gross"]` | 30 |

## Notes / corrections

- **Ticket named the wrong Units visual.** It specified `34fc12de` for Brinno's Units table,
  but Brinno (and the 30-strong brand family) actually render `c00bc2d2` "Units by SKU with RR%".
  Corrected the target and also standardized the 7 dashboards on `34fc12de` for consistency.
- **No app code change** — shared-visual config edit only.
- Validated at the rendered layer (`eclipse.analyticlabs.io`) on Brinno + Pearlie White,
  before/after screenshots captured. **Hard reload (Ctrl+Shift+R)** required to see the change
  (browser caches the column layout).
