# GP-312 — Vendor and Brand dimensions disagree on client names

The same client is named **differently** in `Product[Default Vendor]` and `Brand[Brand]`. Most
happen to match, so the mismatch is invisible until it silently produces an empty or unscoped
surface. Found while scoping the [[GP-310]] remedy. **Status: In Progress**, Low, sprint S8.

## The disagreement (PROD Data Model `74a529b3`)

| Client | `Product[Default Vendor]` | `Brand[Brand]` | |
|---|---|---|---|
| Condor | **`Condor Tool & Knife`** | `Condor` | ❌ different string |
| Penn-Plax | `PENN-PLAX` | `Penn-Plax` | ⚠ case |
| G7th | `G7TH` | `G7th` | ⚠ case |
| NAVAC · Suitical · Coxreels · Dalen · Rain Bird | match | match | ✅ |

**3 of 8 (37%)** carry a display-name ≠ lock-value discrepancy. DAX string comparison is
case-insensitive, so `PENN-PLAX` and `G7TH` resolve today — they are latent, not broken. **Condor
breaks under any matching strategy.**

## Why it bites

Vendor dashboards lock on `Product[Default Vendor]`; MAP Violators is keyed on `Brand[Brand]`.
Cross-scoping works via the bidirectional `Product[Brand] → Brand[Brand]` bridge — **but only with
the dashboard's real lock value**. A parity test keyed on the client's *display* name reported:

```
Condor  ->  0 brands reached, 0 sellers
```

which reads as "Condor has no MAP data". It has 21. Had that not been chased down, Condor would have
shipped a MAP tile rendering **empty** — indistinguishable from the bug [[GP-310]] was opened for.

## Compounding trap — where the lock value actually lives

The enforced value is `explorer_dashboard.filters[].locked_value.value`. The sibling
`restricted_values` is the **dropdown allow-list** and is frequently `[]` even on a hard lock —
reading it reports *every* vendor as unlocked. Any tooling that inspects dashboard locks must read
`locked_value.value`.

## Mitigation — implemented, closes suggested-resolution item 2

`eclipse_ops/_gp310_embed_map_component.py` no longer trusts names. Per vendor it (1) reads the
enforced lock, (2) runs live DAX with that exact value, (3) **refuses to embed** unless the result
is `> 0` rows **and** `<` the unlocked baseline. A vendor that cannot be *proven* to scope is
skipped loudly rather than shipped empty or unscoped. Dry-run across all 8: 8 planned, 0 skipped.

## Still open

1. **Authoritative vendor→brand mapping** — enumerate `Product[Default Vendor]` × `Product[Brand]`
   and record the pairs, rather than relying on string equality.
2. **Decide** whether the underlying dimension values should be reconciled at source, or whether the
   mapping is legitimately many-to-one and should simply be recorded.
