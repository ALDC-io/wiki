**Status:** Done
**Completed:** 2026-05-02

### Framework Change

Renamed service account convention from `CORE_SVC` to `PREFECT_SVC` in `account_registry.py:33-34` (`prefect-connectors` repo). Clearer intent — these are Prefect-only accounts, not Eclipse core accounts.

## Key Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Service account naming | `PREFECT_SVC` (not `CORE_SVC`) | Clearer scope; `CORE_SVC` references Eclipse which is being decommissioned |
| Per-environment users | 3 separate users (QA, TEST, PROD) | Matches framework convention; tighter blast radius than one shared user |
| Prod admin access | `PROD_DG1_CORE_ADMIN` (ACCOUNTADMIN) | `paulrussell` only has SYSADMIN on prod — insufficient for CREATE ROLE/USER |
